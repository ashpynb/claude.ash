# Exemplos (cenas que funcionaram)

| Pasta | Molde | Estilo | O que copiar daqui |
|---|---|---|---|
| `viral07` | E se tu… (1 mês sem se mexer) | boneco de primitivas | quarto, cama, colcha que se molda, deitar/levantar, insertos (cérebro, barras, balança, coração, osso), física de folhas e pipoca |
| `viral09` | E se tu… (redação do Enem) | boneco de primitivas | sala de aula, carteiras, relógio com ponteiros, folha que enche, cartão do tema/chips/selos em HTML, gente em fila |
| `viral08` | Você construiu uma represa | low-poly + corte | terreno de vale, água com ondas, corte transversal com tampas, etiquetas, árvores em cópias, câmera em trilha |
| `corte_transversal` | demo | low-poly + corte | o mínimo do corte com furo, pistões e etiquetas |
| `viral06_lowpoly_modelos` | Você construiu um avião | low-poly com modelos CC0 | GLTFLoader, peças montando |
| `viral04_voce_e` | Você é um ouriço-do-mar | 3D cartoon com luz de cena | fundo do mar, feixes de luz, refrão "Esse é seu…" |
| `flat2d_sergio` | 2D flat (Sérgio 1 mês sem se mexer, versão 2D) | 2D flat em canvas | personagem 2D com expressões, quarto, insertos com raios, operários, balança, barras |
| `viral05_passo_iso` | Passo a passo (telhado) | isométrico técnico | câmera ortográfica isométrica, camadas descendo, tons de cinza |

Cada pasta tem `cena.html` (+ `tempo.js`, `falas.json`, `roteiro.md` com as fontes, `legenda.txt`).
Os 04/05/06 são de antes do kit3d (importam `./vendor/...` direto) e servem de consulta.
Pra começar um vídeo novo a partir de um deles: `python ferramentas/video.py novo SLUG --de viral09`.
