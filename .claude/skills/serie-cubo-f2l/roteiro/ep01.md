## Kit de estudo

**Resumo**

- Cada letra (U R L F D B) gira uma face no sentido horário, olhando de frente pra ela.
- Linha (') = ao contrário; 2 = meia volta (180°).
- x e y giram o cubo inteiro (x como R, y como U): muda a vista, não desfaz nada.

**Quiz**

1. Em R, a coluna da direita (vista de frente) sobe ou desce?
2. O que significa L'?
3. Depois de um y, a cor da frente muda?

<details><summary>Gabarito</summary>

1. Sobe.
2. Girar a face esquerda no sentido anti-horário: a coluna da esquerda sobe.
3. Muda: a face da direita vem pra frente, mas nenhuma peça sai do lugar relativo.

</details>

**Flashcards**

| frente | verso |
|---|---|
| U | face de cima, horário visto de cima (frente vai pra esquerda) |
| R / R' | direita sobe / direita desce |
| L / L' | esquerda desce / esquerda sobe |
| U2 | meia volta no topo |
| x / y | cubo inteiro como R / como U |

**Onde a metáfora falha:** A 'língua do cubo' é só convenção de escrita; o Chefão é o cubo embaralhado, mas a notação não 'derrota' nada, só permite ler os algoritmos.

**⚠️ Conferir**

- Alguns tutoriais usam letras minúsculas (r, u) para giros de duas camadas; aqui não usamos.
